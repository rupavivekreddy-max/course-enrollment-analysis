# Online Course Enrollment Data Analysis

A Python data-analysis project that studies online course enrollments for a batch of 5,707 students. It finds the most taken subjects, measures completion and drop-out, recommends the better instructor for each course, and uses an anti-cheat rule to withhold certificates when a student skipped the videos.

Built with **Python, Pandas, NumPy and Matplotlib** (runs in Google Colab).

---

## Features

- **Dataset builder**: creates 1 to 3 course enrollments per student and saves `course_enrollment_data.csv` (15 columns).
- **Course popularity**: enrollments per course and per instructor.
- **Completion analysis**: overall and course-wise completion, in-progress and drop-out rates.
- **Instructor recommendation report**: ranks the two instructors of each course by completion rate and student rating.
- **Certificate integrity (anti-cheat)**: compares the progress shown on the seek-bar with the genuinely watched time. A completed course gets a certificate only if genuine watch-time is at least 90%.
- **New student enrollment**: interactive input that shows instructor statistics before the student chooses.
- **Statistics**: NumPy and Pandas summaries, top 5 and bottom 5 students.
- **Charts**: six charts saved as PNG files.
- **Completion prediction**: simple rule-based prediction (likely to complete, at risk, likely to drop).

## Dataset (15 columns)

| # | Column | Description |
|---|---|---|
| 1 | `RollNo` | Student roll number |
| 2 | `StudentName` | Student name |
| 3 | `Branch` | Branch code read from the roll number (e.g. `25B11AE001` gives `AE`) |
| 4 | `BatchYear` | Batch year read from the roll number (e.g. `25` gives `2025`) |
| 5 | `Course` | One of 8 courses |
| 6 | `Instructor` | One of 2 instructors per course |
| 7 | `EnrollmentMonth` | Jan-2026 to Jun-2026 |
| 8 | `CourseDurationHours` | Course length in hours (6 to 12) |
| 9 | `WatchedHours` | Hours genuinely watched |
| 10 | `Progress` | Progress % shown on the seek-bar |
| 11 | `GenuineProgress` | Watched hours divided by course duration, in % |
| 12 | `ProgressGap` | `Progress - GenuineProgress` (a large gap means skipping) |
| 13 | `Status` | Completed, In Progress or Dropped |
| 14 | `CertificateStatus` | Issued, Withheld - Rewatch Required, or Not Applicable |
| 15 | `StudentRating` | Rating out of 5 (blank if genuine progress is below 50%) |

> **Note:** the enrollment records are generated by the program with a fixed random seed (`42`), so results are reproducible. Because courses are assigned randomly, popularity differences between courses are small.

## Business rules

| Rule | Logic |
|---|---|
| Status | Progress 100 = Completed, 40 to 99 = In Progress, below 40 = Dropped |
| Certificate | Completed and genuine progress >= 90% = Issued; completed but below 90% = Withheld; otherwise Not Applicable |
| Cheating simulation | 15% of students who reach 80% or more are assumed to skip ahead (show 100% after watching only 5% to 35%) |
| Rating | Only students with at least 50% genuine progress can rate |

## How to run

The script uses `google.colab.files.upload()`, so it is meant for **Google Colab**.

1. Open [Google Colab](https://colab.research.google.com/) and create a new notebook.
2. Paste the contents of `course_enrollment_project.py` into a cell.
3. Run the cell and upload your student CSV when asked. It must have two columns: `RollNo` and `StudentName`.
4. Follow the prompts:
   - Enroll a new student (`y` / `n`).
   - Enter progress and days left for the completion prediction.

**Outputs:** `course_enrollment_data.csv` and these charts:

- `chart_course_enrollments.png`
- `chart_completion_status.png`
- `chart_monthly_enrollments.png`
- `chart_instructor_enrollments.png`
- `chart_certificate_status.png`
- `chart_instructor_ratings.png`

## Privacy

`students_25_26.csv` and `course_enrollment_data.csv` contain real student names and roll numbers. If this repository is **public**, do not upload them as they are. Either keep the repository private, add the CSV files to `.gitignore`, or replace the names with anonymous IDs first.
